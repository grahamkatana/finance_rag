# 2026-10-06 15:30 — 0.2.0: documents, one green, new icon

## Summary
- **Documents screen** (menu → Documents): upload a PDF with progress, list, delete, share / unshare by email.
  No API change: it uses the existing `/api/v1/ingestion/*` endpoints the web app uses.
- **Colours**: one green (`#2C6E49`), used only as a fill. Text on buttons and suggestions is paper, not green.
  `GreenText`, `GreenTint` and `TopBarGreen` are gone.
- **Icon**: `logo.png` (repository root, 1024px) is the master. It was snapped to the app's two exact colours.
  Android foreground is `res/drawable-nodpi/ic_launcher_foreground.png`; the web app uses `frontend/public/`.
- Published as release id 3 (0.2.0, version code 3) on finance.tekbridge.co.za.

## Key decisions
- The PDF is read into memory to send it, capped at 50 MB (marked `ponytail:` in `DocumentsScreen.kt`).
- An upload counts as successful only when the API sends `done`; a stream that just ends is reported as interrupted.
- Share / delete buttons show only on documents you own (`is_owner`), so an admin cannot manage other people's
  documents from the phone even though the API would allow it.
